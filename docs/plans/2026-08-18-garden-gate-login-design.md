# 花园推门登录页设计

## 目标

把当前解释型邮箱登录页改造成一次简短、有记忆点的“回到花园”体验，同时保留 MVP 所需的邮箱验证码登录，不增加新的账户流程或远端依赖。

## 视觉方向

页面采用花花日记本已有的低饱和米白、苔绿、灰绿和陶土色。顶部不再展示花朵图标、`HUĀHUĀ · MVP`、`初次见面` 等标签，而是一幅约占页面上部三分之一的简化花园场景。植物使用弯曲、有生命力的轮廓和少量明暗层次，保持小刺、老背一类扁平但有细节的画风，不使用照片质感、强烈高光或鲜艳色块。

## 入场动效

页面第一次出现时，两扇奶油色花园门从中央向左右推开，并在约 1.2 秒内完全退出画面。门打开约 60% 时，后方的花枝与晨光开始显现，登录表单从下方淡入并轻微上移。门退出后不保留门框，最终画面只留下花园和表单。

花枝在页面停留期间维持幅度很小、节奏不同的左右摆动，花瓣可有一到两枚缓慢飘落，但不循环制造大量粒子。进入验证码步骤时不重复开门，只保持花枝轻摆并切换表单内容。系统启用 `prefers-reduced-motion: reduce` 时，跳过推门和位移动画，直接显示最终构图。

## 信息层级与文案

邮箱步骤只保留标题“登录花花日记本”、辅助文字“用邮箱保存并找回你的花园”、邮箱输入框和“获取验证码”按钮。验证码步骤标题改为“输入邮箱验证码”，显示当前邮箱、六位验证码输入、重新发送和“进入我的花园”按钮。隐私说明压缩为一行弱提示，不再使用书信、地址、短信笺等比喻，避免掩盖必须登录的事实。

## 交互与状态

邮箱格式校验、发送验证码、自动聚焦、输入六位后自动验证、倒计时、修改邮箱和错误提示沿用现有逻辑。请求进行中禁用相应按钮，并使用简短的“正在发送…”或“正在登录…”状态。错误信息继续放在输入区域附近，不能因动画改变位置或被花园插画遮挡。

## 实现边界

花园、门和植物使用页面内 SVG 与 CSS 动画完成，不新增图片请求或第三方动效库。现有 CloudBase 账户服务和数据流保持不变，本次只改登录页组件、样式及相关表现测试。页面需在 390 × 844 的现有设备框内完整显示，并兼顾更矮的移动视口。

## 验证标准

普通入口首次加载能看到门完全退出、花园出现和表单淡入；最终页面没有旧花朵图标和冗长文案；邮箱与验证码两个步骤均可操作；固定开发验证码仍不可见；演示入口与登录后的首页不受影响；减少动态效果模式下内容立即可用。
