# 弹性花园口袋动效设计

## 目标

把首页进入“二楼花园”的下拉手势从页面与手指一比一移动，升级为具有阻尼、预览和弹性吸附的空间切换。用户下拉时，首页顶部中央逐渐鼓出一个半圆口袋，口袋内部提前露出花园的光影与植物；超过阈值后松手进入完整花园，未超过阈值则柔和回弹。

## 视觉方向

口袋从首页顶部中央出现，不做整条顶部边缘的幕布，也不做写实布料。形态保持花花日记本的克制手帐感：奶油纸张边缘、柔和阴影、低饱和绿色光晕与少量叶影。口袋内部直接复用当前花园场景，不创建第二套假预览图。

## 手势与动效

- 前 20px 为预备区：首页几乎不移动，只出现很浅的弧形压痕，避免轻微滚动误触。
- 超过预备区后采用分段阻尼。手指继续下拉时，首页位移约为有效拖动距离的 0.55–0.7 倍，拖得越远阻力越明显。
- 口袋的宽度、深度、圆角、阴影和花园清晰度统一由 0–1 的拖动进度驱动；不能各自使用互不相关的计时动画。
- 达到切换阈值后，口袋边缘轻微拉伸，并显示低干扰的“松手去花园”。
- 未达到阈值松手：首页与口袋使用弹性缓动收回。
- 达到阈值松手：口袋先扩展为大弧面，再带动首页向下滑开，约 520ms 吸附到花园。
- 从花园上推返回首页时使用同一套进度与相反方向的弹性收合。

## 状态与实现边界

`DiaryGardenFloor` 保留现有 `floor`、`dragging` 和手势轴判断，新增归一化拖动进度和是否越过阈值的派生状态。阻尼由纯函数计算，便于单元测试；视觉参数通过 CSS 自定义属性传给口袋层。口袋层位于花园场景与首页纸张之间，只负责裁切和视觉反馈，不拦截点击，也不改变首页、花园横向翻页或全局拍照按钮的交互。

不引入第三方动画库，不加入音效或震动，不改变花园业务数据与路由。`prefers-reduced-motion` 下取消弹簧和形变，只保留简短的淡入与位置切换。

## 验收标准

1. 轻微下拉不会明显移动整页，也不会误进花园。
2. 持续下拉时能感到阻尼逐渐增强，半圆口袋从顶部中央连续长大。
3. 口袋内能提前看到当前真实花园，而不是静态占位图。
4. 阈值上下的松手行为明确：未达到则回弹，达到则进入花园。
5. 花园上推返回首页同样有连续进度和缓动，不出现跳帧或瞬移。
6. 花园横向翻页、首页纵向滚动、全局拍照按钮保持原有行为。
7. 桌面预览与移动端宽度均可用，减少动态效果设置下仍能完成切换。
