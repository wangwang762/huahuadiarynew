# 全屏花园门登录页 V2 设计

## 复盘与目标

V1 的门只覆盖上半屏，并以普通平移方式离场，缺少透视和空间转换；门后的花园是临时绘制的基础图形，与首页植物的细节和气质不一致；花园与表单之间存在生硬横切。V2 不继续修补 V1，而是重建为一个完整的“推门进入自己的花园”开场，并确保门后画面直接延续首页的植物资产和低饱和艺术风格。

## 核心场景

初始画面是一扇覆盖整个手机内容区域的深灰绿色双开木门，门框贴近屏幕四周，门板具备克制的木纹、内嵌线框、内侧阴影和黄铜把手。中央门缝先透出一条暖光，随后两扇门围绕左右门轴向屏幕深处旋转，产生真实的透视收窄和阴影变化；门完全打开后整体淡出，不在最终画面保留门框。

门后是分为三层的庭院。远景为柔和晨光、低对比墙面和模糊绿影；中景复用项目现有植物切图，以花架和盆栽组成与首页一致的花园；近景使用两侧较大的叶片轮廓遮挡边缘，并在开门过程中产生幅度不同的视差。植物只进行小幅、不同步的摆动，最多一到两片叶子缓慢飘过，不做持续粒子雨。

## 最终页面构图

门完全退场后，花园占据画面背景而不是单独的横向插画块。上部庭院约占 43% 高度，近景叶片自然延伸到中部；登录区域是一张放在庭院前景中的奶油色日记纸，带极轻的纸纹、细描边、柔和投影和顶部手写日期装饰，但不使用玻璃拟态。日记纸与花园有重叠关系，以消除 V1 的生硬分割。

邮箱状态只显示“登录花花日记本”、邮箱输入框、“获取验证码”按钮和一行弱隐私说明；“用邮箱保存并找回你的花园”作为标题下方的一句短辅助文案。验证码状态在同一张纸上切换为“输入邮箱验证码”，保留邮箱、六位输入、倒计时和进入按钮，不重播门动画。

## 动效节奏

进入后的前 180 毫秒保持门闭合；180–430 毫秒门缝暖光增强；280–1380 毫秒双门通过 `rotateY` 和轻微横向位移向内打开，门板阴影随角度减弱；620–1500 毫秒庭院三层分别以不同速度轻微放大并清晰；980–1580 毫秒日记纸从下方上移 18 像素并淡入。总时长约 1.6 秒，表单出现后可立即操作。

系统启用 `prefers-reduced-motion: reduce` 时隐藏门层、取消视差和摆动，直接展示最终花园与表单。验证码步骤只使用 250 毫秒以内的内容淡入，不重新触发场景开场。

## 技术边界

继续使用现有 React、SVG、CSS 和本地植物切图，不新增动效库或网络图片。CloudBase 邮箱 OTP、表单校验、错误处理和数据加载逻辑保持不变。门、光、远景和近景轮廓可用 CSS 与内联 SVG 绘制，中景植物优先复用 `PLANT_CUTOUTS` 中与首页一致的资源。V1 的基础小花 SVG 和旧门样式应完全删除，防止两套视觉叠加。

## 验收标准

首帧是完整的全屏木门；中间帧能明显看出门板围绕门轴旋开而非平移；最终帧不残留门和门框；庭院植物与首页素材同源并有前中远景；日记纸与花园重叠且没有横向硬切；邮箱和验证码流程仍可正常操作；固定开发验证码不出现；390 × 844 和矮屏均无主要内容裁切；减少动态效果模式内容立即可用。
