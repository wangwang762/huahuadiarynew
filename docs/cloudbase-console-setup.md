# CloudBase 控制台配置清单

环境：`huahuadiary-d4gajnlumc8432f6c`  
地域：上海（`ap-shanghai`）

代码已经连接这个环境，但真实验证码和远端数据只有在下面配置完成后才能工作。不要把 SecretId、SecretKey、腾讯云密码或 SMTP 密码复制到前端代码或聊天中。

## 1. 开启邮箱验证码登录

进入 CloudBase 控制台，选择当前环境，然后进入“身份认证 → 登录方式”。开启“邮箱验证码／邮箱 OTP”登录，并允许不存在的邮箱在第一次验证后创建用户。MVP 不需要开启短信、用户名密码或匿名登录。

## 2. 创建三个文档数据库集合

进入“数据库 → 文档数据库”，创建以下集合，名称必须完全一致：

- `profiles`
- `plants`
- `diary_entries`

本期查询只按 `ownerId` 过滤并在浏览器内排序，不需要创建复合索引。若控制台要求索引，为三个集合分别创建 `ownerId` 的普通索引即可。

## 3. 配置集合安全规则

分别打开三个集合的安全规则，把 [cloudbase-security-rules.json](../cloudbase-security-rules.json) 中对应集合的四条表达式复制进去。规则含义是：必须登录，创建时 `ownerId` 必须等于当前 CloudBase UID，之后只有这个 UID 可以读取、修改或删除该记录。

先在测试环境验证规则；不要为了图省事选择“所有用户可读写”。`profiles`、`plants` 和 `diary_entries` 中都可能包含用户邮箱或私人日记。

## 4. 添加 Web 安全来源

进入“环境设置／安全来源／Web 安全域名”，开发阶段添加本机预览来源 `http://127.0.0.1:4176` 和 `http://localhost:4176`；正式部署后再加入真实 HTTPS 域名，并删除不再使用的测试来源。如果控制台只接受域名、不接受协议或端口，则按界面提示分别填写 `127.0.0.1` 与 `localhost`。

## 5. 验证

正常打开 `花花日记本.html`，页面不应显示固定开发验证码。填写真实邮箱后应收到六位验证码，验证成功的新用户进入空花园；添加第一盆植物后，刷新或更换设备用同一邮箱登录，植物与第一篇日记仍应存在。

若需要继续看 26 盆设计样例，使用 `花花日记本.html?demo=1`。这个模式完全使用本地演示数据，不会写入 CloudBase。
